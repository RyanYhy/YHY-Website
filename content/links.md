## 申请友链 {#apply}

> [!NOTE] 先互加再提交
> 请先把本站加到你的友链页，再通过 GitHub Issue 申请，或直接提 PR 修改 `data/friends.yaml`。

本站信息：

{{< friends-self >}}

申请方式：

- 开 [Issue](https://github.com/RyanYhy/YHY-Website/issues/new?template=friend-link.yml)，标题会带上「申请友链」
- 或 PR：在 [`data/friends.yaml`](https://github.com/RyanYhy/YHY-Website/blob/main/data/friends.yaml) 增加一条 `name` / `url` / `avatar` / `desc`

本站源码：[RyanYhy/YHY-Website](https://github.com/RyanYhy/YHY-Website)。
